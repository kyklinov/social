# Дэшборд статистики соцсетей

Автоматический сбор статистики из соцсетей и наглядный дэшборд на GitHub Pages.
Сейчас подключена **VK** — остальные платформы (YouTube, Instagram, Facebook, Telegram)
добавляются по той же схеме: `collectors/<platform>_collector.py` + строка в workflow +
раздел на дэшборде.

## Структура проекта

```
collectors/vk_collector.py       — скрипт сбора данных из VK API
data/vk/history.json             — история роста подписчиков (копится со временем)
data/vk/latest.json              — последний снимок: охват, демография, топ-посты
dashboard/index.html             — сам дэшборд (Chart.js), читает файлы из data/
.github/workflows/collect-vk.yml — GitHub Actions: запускает сбор раз в неделю
```

Сейчас в `data/vk/` лежат **демонстрационные данные**, чтобы дэшборд сразу
можно было открыть и посмотреть, как он выглядит. После первого реального
запуска коллектора они заменятся настоящими.

## Шаг 1. Получить токен VK

1. Открой сообщество → **Управление** → **Работа с API** → **Создать ключ доступа**.
2. Отметь права: **Статистика сообщества**.
3. Скопируй токен — он понадобится на шаге 3.
4. Узнай числовой ID сообщества (без минуса) — он есть в том же разделе
   или в адресной строке при переходе в раздел статистики.

## Шаг 2. Создать репозиторий на GitHub

1. Создай новый репозиторий (публичный — тогда GitHub Pages и Actions
   бесплатны без ограничений; приватный тоже подойдёт, но с лимитом
   бесплатных минут Actions в месяц, для еженедельного запуска этого
   с большим запасом хватит).
2. Загрузи в него содержимое этой папки (`git init`, `git add .`,
   `git commit`, `git remote add origin ...`, `git push`).

## Шаг 3. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

- `VK_TOKEN` — токен из шага 1
- `VK_GROUP_ID` — числовой ID сообщества

## Шаг 4. Включить GitHub Pages

**Settings → Pages → Source** → выбери ветку `main` и папку `/dashboard`
(или `/root`, если переместишь `dashboard/index.html` в корень — смотри
Шаг 6 по кастомизации).

После этого дэшборд будет доступен по адресу вида:
`https://<твой-логин>.github.io/<имя-репозитория>/`

## Шаг 5. Проверить сбор данных вручную

**Actions → Collect VK stats → Run workflow** — запустит сбор прямо сейчас,
не дожидаясь понедельника. Проверь, что в `data/vk/` обновились файлы
и появился новый коммит от `github-actions[bot]`.

После этого сборка данных дальше будет идти автоматически каждый
понедельник в 06:00 UTC — время и день можно поменять в файле
`.github/workflows/collect-vk.yml`, строка `cron:`.

## Шаг 6. Дальше — по твоему усмотрению

- **Добавить YouTube / Instagram / Facebook / Telegram**: пишем ещё один
  `collectors/<platform>_collector.py`, добавляем шаг в workflow (или
  отдельный workflow-файл), дэшборд дополняем вкладкой — структура уже
  для этого заложена (кнопки платформ в шапке дэшборда).
- **История дольше 12 месяцев**: копится сама, файл `history.json` не
  перезаписывается, а пополняется.
- **Активность в ЛС сообщества**: VK API не отдаёт эту статистику напрямую
  через `stats.get` — понадобится отдельный подход (Callback API или
  токен с правом `messages`). Обсудим отдельно, когда дойдём до этого пункта.
