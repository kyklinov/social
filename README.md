Дэшборд статистики YouTube — CarX Technologies
<!-- README.md — v3.0 -->
Автоматический сбор статистики канала YouTube и наглядный дэшборд на GitHub Pages.
Данные обновляются раз в день через GitHub Actions.
Дэшборд: `https://kyklinov.github.io/social/`
Структура проекта
```
collectors/youtube\_collector.py       — сбор статистики YouTube
docs/index.html                       — дэшборд (Chart.js), публикуется через GitHub Pages
docs/data/youtube/history.json        — история роста подписчиков
docs/data/youtube/latest.json         — последний снимок статистики
.github/workflows/collect-youtube.yml — ежедневный автосбор
requirements.txt                      — зависимости Python
```
Функционал дэшборда (сверху вниз)
Карточки сверху
Подписчиков (с приростом за период), просмотров всего за всё время канала, число видео, топ-страна по просмотрам за последние 28 дней.
Динамика подписчиков
График роста числа подписчиков за всю собранную историю (копится с каждым запуском сборщика, не только за последние N дней).
Пол аудитории
Круговая диаграмма (мужчины/женщины) за последние 28 дней.
Вовлечённость и показы (за 28 дней)
Просмотрено часов (estimated watch time)
Средняя длительность просмотра
Досматриваемость (% от длины ролика)
Показы превью (impressions)
CTR превью (% кликов по показам)
Показы и CTR доступны не для всех каналов — зависит от того, начал ли YouTube показывать эту метрику для конкретного канала. Если недоступно, отображаются нули, сбор остальных данных при этом не прерывается.
Источники трафика (за 28 дней)
Откуда зрители попадают на видео — поиск YouTube, рекомендации, подписки/главная, внешние сайты, плейлисты, лента Shorts и т.д. В процентах от общего числа просмотров за период.
Приток / отток подписчиков (за 28 дней)
Отдельный график: сколько подписалось и сколько отписалось за период (не только итоговая разница).
География и индустрия платежей
Объединённая таблица:
Просмотры (YouTube) — топ-10 стран по просмотрам за 28 дней, данные YouTube Analytics, обновляются автоматически.
IAP-выручка мобильных игр, 2025 и % от мировой IAP-выручки — справочные статические данные по индустрии для тех же стран (не про сам канал). Источник по странам: Allcorrect Games, «Mobile Game Market Index 2025» (App Store + Google Play, без учёта Android в Китае и D2C-платежей). Мировая выручка для расчёта доли: Sensor Tower, «State of Mobile 2026» — $81,75 млрд за 2025 год.
Прочерк в IAP-колонках означает, что данные по стране недоступны или несопоставимы с остальными (например, Россия исключена из большинства отраслевых отчётов из-за ограничений App Store/Google Play с 2022 года).
Эти два столбца не обновляются автоматически — только вручную, при необходимости актуализировать данные.
Возраст аудитории
Разбивка по возрастным группам (13–17, 18–24 и т.д.) за последние 28 дней.
Устройства
Круговая диаграмма и таблица по типу устройства (мобильные, компьютер, планшет, ТВ, игровая консоль). Отдельно — таблица по операционным системам (Android, iOS, Windows, macOS и др.), независимо от типа устройства.
Топ видео за последние 30 дней
До 10 роликов, опубликованных за последние 30 дней, отсортированы по просмотрам от большего к меньшему.
Топ за всё время
Все публичные видео канала, отсортированы по просмотрам. Постраничная навигация — по 10 роликов на страницу, кнопки «Назад/Вперёд» и счётчик страниц.
Как проверить сбор данных вручную
Actions → Collect YouTube stats → Run workflow — запускает сбор прямо сейчас, не дожидаясь расписания.
Как изменить частоту сбора
Файл `.github/workflows/collect-youtube.yml`, строка `cron: '15 6 \* \* \*'` — стандартный формат cron-расписания (сейчас: каждый день в 06:15 UTC).
Если понадобится заново настроить доступ к YouTube API
Google Cloud Console → создать проект → включить YouTube Data API v3 и YouTube Analytics API.
OAuth consent screen → тип External → добавить себя в Test users → перевести в статус Production через Publish App (иначе токен истекает каждые ~7 дней).
Credentials → OAuth client ID → тип Desktop app → скачать JSON.
Локально запустить `get\_youtube\_token.py` (использует `google-auth-oauthlib`, сам открывает браузер) — получить `client\_id`, `client\_secret`, `refresh\_token`.
